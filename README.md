# Mathews Dental Care — clinic website concept

A single-page marketing website concept for **Mathews Dental Care**, a dental clinic in Kamothe, Navi Mumbai run by Dr. Manoj Mathews (BDS, 20+ years of practice).

> Concept build. The page was generated with [Lovable](https://lovable.dev) from a clinic knowledge base and design prompt written by Tanmay Gawade. It isn't currently deployed.

## What's on the page

- Hero with a "book a visit" call to action
- Services: general consultation, cleaning & whitening, root canal, implants, aligners/braces, cosmetic smile makeover, emergency care
- "Why patients choose us" (sterilisation and hospital-grade protocols)
- Meet the dentist, patient stories, inside-the-clinic gallery (carousel)
- A quick booking **request form** (preferred treatment and notes) with a confirmation state. It's front-end only, with no scheduling backend.
- FAQ

## Stack

TanStack Start, React 19, Vite 7, Tailwind CSS 4, shadcn/ui, Embla Carousel, Lucide icons. Cloudflare Workers config (`wrangler.jsonc`) included.

## Run locally

```bash
bun install
bun run dev
```
